Categorias

Crie, renomeie ou apague categorias. Use a chave à esquerda para ativar ou desativar: categoria desativada some das listas de lançamento, mas o histórico continua.

Ao renomear, todos os lançamentos antigos mudam junto. Ao apagar uma categoria que já foi usada, você escolhe para qual outra categoria os lançamentos vão.

🎯 Premissas

O melhor dia de compra é o dia em que começa a fatura nova (a anterior fecha no dia anterior). Veja no app do banco, na fatura: “melhor data de compra”.
Referência: CDI 14,75% bruto ≈ 12,5% líquido (IR 15%). Se a Selic cair, use um valor menor (seu relatório usa 11,16%).

🧰 Dados

Os dados ficam só neste navegador. Exporte um backup de vez em quando. Backups da versão anterior (acompanhamento) também podem ser importados.
